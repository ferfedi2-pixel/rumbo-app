# RUMBO · variante Claude

Variante independiente de la versión 1. Conserva los cálculos, estados y almacenamiento local. Las carteras modelo muestran categorías neutras en vez de activos concretos: Refugio 60/40/0, Travesía 65/25/10 y Cumbre 70/0/30, respectivamente renta variable, renta fija y efectivo. Las tasas de Horizonte son hipótesis, no garantías.

Aplicación personal para configurar, rebalancear y proyectar una cartera de inversión a largo plazo.
